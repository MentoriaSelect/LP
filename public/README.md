# Pasta de Assets — Landing Page

Use esta pasta para enviar os arquivos necessários para a criação da landing page.
Após o upload, peça ao Claude para ler os arquivos e ele os utilizará no desenvolvimento.

## Estrutura

```
public/
├── textos/     → Copys, headlines, descrições, listas de benefícios, CTAs
├── fontes/     → Arquivos de fonte (.ttf, .woff, .woff2, .otf)
├── imagens/    → Logos, fotos, ícones, banners (.png, .jpg, .svg, .webp)
├── videos/     → Vídeos de fundo ou de apresentação (.mp4, .webm)
└── outros/     → Qualquer outro arquivo de referência
```

## Como usar

1. Faça upload dos arquivos nas pastas correspondentes via GitHub (arrastar e soltar na interface web funciona)
2. Faça commit das alterações
3. Diga ao Claude quais arquivos você enviou e peça para ele ler e usar no desenvolvimento
